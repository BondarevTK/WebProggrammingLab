# Мини-социальная сеть — REST API на FastAPI

Лабораторная работа №2: добавление новой возможности в веб-приложение
с помощью HTML, JavaScript и Python.

## Описание

Проект реализует простую страницу для публикации, просмотра,
редактирования и удаления твитов. Бэкенд написан на **FastAPI** и
отдаёт данные в формате JSON. Фронтенд — статические файлы
(`index.html`, `app.js`, `style.css`), которые обращаются к API через
`fetch`. Фреймворки на фронтенде не используются.

## Стек технологий

- **Python 3.11+**
- **FastAPI** — REST API
- **Pydantic** — валидация входных и выходных данных
- **Uvicorn** — ASGI-сервер
- **HTML + CSS + JavaScript** — фронтенд
- **pytest + httpx** — тесты
